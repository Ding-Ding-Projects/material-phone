# Upstream provenance

Material Phone is based on inherited Linphone desktop source.

- Upstream project: [BelledonneCommunications/linphone-desktop](https://github.com/BelledonneCommunications/linphone-desktop)
- Upstream product information: [Linphone](https://www.linphone.org/linphone-softphone/)
- Upstream public documentation: [Linphone public wiki](https://wiki.linphone.org/xwiki/wiki/public/view/Linphone/)
- Inherited license: [LICENSE.txt](LICENSE.txt)

The `site/`, `docs/`, and Material Phone project-record files describe this repository's design and documentation direction. They do not claim ownership of inherited Linphone code, branding, protocols, or prior release history. Material Phone documentation also does not claim that the inherited desktop source already implements the feature contracts inventoried for the redesign.

The repository keeps the upstream source relationship explicit so future updates can distinguish:

1. inherited upstream behavior;
2. Material Phone documentation and design intent;
3. verified Material Phone implementation evidence.
